# USB-C 3.3 V LDO demo：需求规格

这是设计的唯一需求来源，也是 agent 的工作记忆。需求变了，先在分支里改这里，再改设计。每条需求有编号（R-xx），选料、设计决定、门禁指标、仿真和上电测试都引用编号。

状态：已评审（示例工程，2026-10-10）

## 1. 概述

- 用途：pcb-pipeline 的端到端示例。从 USB-C 取 5 V，输出 3.3 V 给面包板上的小电路，带电源指示灯。
- 使用场景：桌面，室温，任意 USB-C 充电器或电脑口，线长不超过 1 m。
- 数量与目标成本：10 套，物料不超过 1.2 美元/套（不含 PCB、贴片费和扩展库上料费；原目标 0.5 美元，见 D-0003）。
- 参考设计：各器件数据手册的典型应用电路，不派生自其他工程。

## 3. 约束

- 机械：25 × 18 mm，圆角 1 mm；无安装孔（示例板）。
- 制造：嘉立创双层板标准工艺，最小线宽/间距 0.15 mm，过孔 0.6/0.3 mm；SMT 贴片，排针手焊或通孔贴装。
- 电气：VBUS 走线 ≥ 0.4 mm；LDO 输入、输出电容各距对应引脚 ≤ 3 mm（数据手册布局建议）。
- 许可：本设计 CERN-OHL-S-2.0；使用 KiCad 自带符号与封装（CC-BY-SA 4.0 加例外条款）。
