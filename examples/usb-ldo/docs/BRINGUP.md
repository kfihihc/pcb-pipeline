# 上电与测试记录

测试项从 SPEC 的需求推出，编号 T-xx。实测结果和偏差都记在这里；确认的设计缺陷转到 `ERRATA.md`，并尽量变成门禁指标、仿真断言或连接意图，下一版不再犯。

## 上电前检查

- [ ] 目检：D1 阴极（绿色角标，KT-0603R p.2）朝向与丝印一致；J1 外壳四个插脚焊透（1.6 mm 板厚，见 D-0003 待确认）
- [ ] VBUS、3V3 对 GND 阻抗（不上电）：VBUS > 10 kΩ，3V3 > 1 kΩ
- [ ] 限流电源从 J2.3 加 5.0 V，电流上限 20 mA：空载电流应 < 3 mA（LED 约 1.4 mA + LDO 静态 4 µA 以下）
