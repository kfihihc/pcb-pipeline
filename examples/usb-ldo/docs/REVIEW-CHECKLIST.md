# 审查清单

审查分三次：原理图冻结前、布线完成后、发布前。每次都附门禁报告（`reports/summary.json`）和与上一版的对比（`pcbkit/board_diff.py`）。发现的问题写成 issue 或 `docs/reviews/YYYY-MM-DD-<阶段>.md`，标明严重度（阻断 / 应改 / 建议）和依据（数据手册页码、规范条款、计算）。

## 原理图

- [ ] 每个器件的引脚连接对照数据手册的引脚表和典型应用电路（facts.toml 有页码）
- [ ] 电源：输入范围与绝对最大值（含热插拔、反接、浪涌）、上电时序、使能与复位、退耦与储能电容（含直流偏压降额）
- [ ] 每个 IC 的未用引脚处理（悬空 / 上下拉 / 接地）符合数据手册
- [ ] 上拉/下拉、默认电平、启动配置引脚（strapping）
- [ ] 接口电平匹配、ESD 保护、连接器引脚定义与线缆一致
- [ ] 模拟部分：参考电压、滤波、地的划分
- [ ] BOM：每个装配器件有 MPN 和 LCSC，额定电压/功率/温度有裕量，基础库优先，替代料
- [ ] 连接意图（design/intent.toml）覆盖了所有功能性连接

## 布局与布线

- [ ] 连接器、按键、安装孔、指示灯位置与机械约束一致
- [ ] 去耦电容紧靠电源脚，回流路径短；开关电源热环路面积最小
- [ ] 参考平面完整（不跨分割走高速或敏感信号），换层处有回流过孔
- [ ] 线宽满足电流（温升计算），开关节点、功率路径没有被颈缩到最小线宽
- [ ] 差分对与长度要求、阻抗（叠层与线宽由板厂叠层计算）
- [ ] 天线与射频净空、晶振周边
- [ ] 散热：裸露焊盘过孔、铜皮面积
- [ ] 丝印：位号可读、极性与 pin 1 标记、版本号与许可
- [ ] 项目指标（checks/metrics.toml）全部通过，且不比上一版差

## 发布

- [ ] 门禁全部通过，制造包由 `pcbkit/release.py` 从干净的提交生成
- [ ] 板厂预览：Gerber 层、钻孔、板框；贴片预览逐个核对旋转角和极性
- [ ] BOM 与坐标一一对应，库存和价格快照（带日期）
- [ ] CHANGELOG、SPEC 状态、DECISIONS 已更新，标签与附件一致
