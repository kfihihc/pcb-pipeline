# 连接意图 design/intent.toml

门禁 `netlist` 检查会先用 `kicad-cli` 从原理图导出网表，再逐条核对这些断言。引脚写成 `位号.引脚号`。引脚号以数据手册和 KiCad 符号为准，不用引脚名，因为引脚名可能重复。

```toml
[[connect]]                      # 这些引脚在同一个网络上；net 可以不写，写了就同时核对网络名
name = "cc1_pulldown"            # R-01, D-0001
pins = ["J1.A5", "R1.1"]
net = "CC1"

[[isolate]]                      # 这些引脚两两不在同一网络（未连接的引脚不算违反）
name = "cc_pins_separate"
pins = ["J1.A5", "J1.B5"]

[[net]]                          # 网络恰好由这些引脚组成，多一个少一个都报错
name = "+3V3"
pins = ["U1.3", "C2.1", "R3.1", "J2.1"]

[parts]
required = ["U1", "J1"]          # 必须存在，而且不是 DNP（除非也列在 dnp 里）
dnp = ["R51"]                    # 必须存在，而且是 DNP
absent = ["R10"]                 # 必须不存在（例如删掉了的调试电阻）
```

## 写什么

| 来源 | 写成 |
| --- | --- |
| SPEC 接口表（连接器引脚定义） | `connect`，每个连接器引脚对到目标芯片引脚 |
| 数据手册典型应用 | 去耦电容和使能、复位网络用 `net` 或 `connect`；不能接在一起的用 `isolate`（例如 USB D+ 和 D−，电池负极和 GND） |
| 参考设计对比的结论 | 采纳的接法用 `connect`；有意不同的地方加注释说明 |
| 修复过的缺陷（ERRATA） | 用断言防止回退。S3 例子：`isolate ["J1.2", "U1.57"]`，电池负极不能接地，否则会旁路反接保护 MOS |
| 二选一、选装 | `[parts] dnp` / `required` |

## 不写什么

- 不从当前网表整份导出成断言：这样只能防“改动”，防不住“错误”，而且每次正常修改都会失败。只写有功能意义的连接。
- 不写布局和线宽相关的约束，那些属于 `checks/metrics.toml`。
