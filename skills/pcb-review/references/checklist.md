# 审查清单（细化）

工程模板里的 `docs/REVIEW-CHECKLIST.md` 是简表，这里是每项具体怎么查、用什么证据。标了“门禁”的项，门禁通过后只需抽查。

## 原理图

| 项 | 怎么查 | 证据 |
| --- | --- | --- |
| 引脚接法 | 每个 IC 的每个引脚对照 facts.toml 的引脚表和典型应用；用 `refnet.py around` 列出来逐行看 | facts 页码，参考设计对比 |
| 电源树 | 每路电源从哪来、最大电流、压差和功耗、上电顺序、使能 | facts 的 characteristic；功耗手算 |
| 绝对最大值 | 每个电源输入的最坏情况（热插拔、反接、浪涌、感性关断）对照 abs_max | sim 基准；没有基准的写“待确认” |
| 未用引脚 | 按数据手册处理：悬空、上拉、下拉或接地；输入引脚不能悬空 | facts；ERC（门禁） |
| 启动配置和复位 | 默认电平、上下拉阻值、RC 时间常数 | 数据手册的启动配置表 |
| 电容 | 有效容值（直流偏压）、额定电压、稳定性对 ESR 的要求 | facts caveat；厂商曲线 |
| 接口 | 电平匹配、ESD、连接器引脚定义与线缆的对应、USB CC 和数据线 | SPEC 接口表；连接意图（门禁） |
| BOM | 每个装配件有 MPN 和 LCSC（门禁）；额定值有裕量；基础库优先；有替代料 | parts.csv；`jlc_parts.py check` |
| 意图覆盖 | 每条带“连接意图”验证方式的需求，在 intent.toml 里都有对应 | SPEC 对照 intent.toml |

## 版图

| 项 | 怎么查 | 证据 |
| --- | --- | --- |
| 机械 | 连接器、按键、指示灯、安装孔的位置和朝向，对照 SPEC；连接器的“板边线”是否对齐板框 | 渲染图；placement.toml 的 why |
| 金属件下方 | USB 外壳、屏蔽罩、晶振外壳下面不能有异网走线和过孔 | top.png；禁布区 |
| 盘中孔 | 细间距焊盘和连接器焊盘上的过孔 | 渲染图 |
| 去耦 | 电容到电源脚的距离、回流路径（电容地端到 IC 地脚） | metrics decoupling_mm |
| 电流路径 | 线宽满足电流（IPC-2152；KiCadRoutingTools 的日志会给出瓶颈载流）；颈缩只能出现在焊盘入口 | metrics min_track_width_mm |
| 参考平面 | 地平面是否完整（zone_islands）；敏感线和高速线下面有没有跨越分割；换层处有没有回流过孔 | metrics；pcb.pdf 逐层看 |
| 开关电源 | 热环路面积、开关节点铜皮大小、反馈走线远离开关节点 | 渲染图；预布线文件 |
| 射频和天线 | 净空区、馈线全程一层、离异网过孔的距离（S3：≥ 0.5 mm） | metrics items_in_area |
| 规则 | `.kicad_dru` 已加载（门禁 rules）；每条自定义规则都核实过真的会触发 | 副本里构造违规 |
| 丝印和装配 | 位号可读、不压焊盘（DRC）；pin 1 和极性标记；版本号和许可 | 渲染图；caveats.md |
